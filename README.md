# Student social media & mental health impact analysis
An interactive Power BI dashboard that analyses the relationship between social media usage and students' mental health, exploring usage patterns, age groups, screen time and their potential impact on student well-being through data visualization.

##📌 Project Overview

Student Social Media & Mental Health Impact Analysis is a data analytics project developed using Microsoft Power BI to explore the relationship between social media usage patterns and students' mental well-being.

The project uses student-related data to examine social media habits, screen time, age groups and mental health indicators. Through data cleaning, transformation and interactive visualizations, the dashboard presents meaningful insights into how digital media usage may be associated with students' well-being.

##🎯 Project Objectives

- Analyse students' social media usage patterns.
- Explore screen time and usage frequency.
- Examine patterns across different age groups.
- Understand the relationship between social media habits and mental health indicators.
- Identify trends and patterns using interactive visualizations.
- Present analytical findings through an interactive dashboard

##📊 Dashboard Features

- Social Media Usage Analysis: Explores students' social media habits and usage patterns.
- Screen Time Analysis: Examines screen time distribution and usage trends.
- Age Group Analysis: Compares patterns across different student age groups.
- Mental Health Insights: Explores mental health indicators in relation to social media usage.
- Interactive Visualizations: Provides filters and charts for exploring different aspects of the dataset.
